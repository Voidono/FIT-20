# FIT Runner dev project

A tiny Godot 4.4 project that exists only to test the module on its own. **Copy `minigames/fit_runner/` into the main game and read
`minigames/fit_runner/MERGE.md`.** `dev/` and the project settings here are not part of the module.

- Open `project.godot` in Godot 4.4 and press F5. `dev/harness.tscn` launches FIT Runner with the debug overlay on, in Vietnamese.
- Hold Space / left mouse / touch to push, let go to recover and tap the bar when it appears. Esc or P pauses. F1 or the DBG button opens tuning.
- `dev/harness.gd` shows the whole host contract in about 20 lines. `dev/example_level1.gd` shows a Level 1 menu awarding Time Stone #1.
