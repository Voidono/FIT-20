# FIT Runner (module) - Godot 4.4, GDScript only

A marathon-pacing minigame for *FIT: THE TIME STONE*. Hold to push, release to recover, tap a timing bar while resting to get stamina back
faster. One input, one effort value (0-1). **To merge it into the main game, read `MERGE.md`.** Landscape 16:9 on a 640x360 canvas,
Vietnamese + English, all art swappable (`assets/README.md`).

## Read this first
Nobody has run this in Godot. It was built where there is no Godot: the stamina model was checked in a Python mirror, and the scripts and
scenes were cross-checked mechanically (every script reference, node, export, signal, connection and translation key resolves). Scenes were
generated by a script, so open each one in the editor and press Ctrl+S once. If something breaks, send me the first error; missing nodes
report themselves as `node 'X' not found`.

## Public API (everything else is internal, class names start with `Fr`)
| Class | Use |
|---|---|
| `FitRunnerLauncher` | `create(config)` / `launch(parent, config)`: installs strings, instances the scene, applies the config |
| `FitRunnerConfig` | optional settings: `tuning`, `qte`, `attempt`, `assist_level`, `debug_enabled`, `push_action`, `autostart`... |
| `FitRunner` | the scene root: `run_finished(result)`, `quit_requested`, `start()`, `toggle_pause()` |
| `FitRunnerResult` | `passed`, `time_sec`, `stars`, `walls_hit`, `attempt`, `par_time`, `qte_perfect`, `qte_good`, `qte_miss`, `to_dict()` |

## Layout
```
minigames/fit_runner/
  fit_runner.tscn            entry scene
  scenes/  character, course, props, ui, debug      (all editable in the editor)
  scripts/ api, sim, character, course, qte, ui, debug
  assets/  character, ui, world, branding, fonts    (placeholder art, see assets/README.md)
  resources/ qte_easy / normal / hard .tres
  tools/   relocate.py, check_conflicts.py, strategy_sim.gd
  MERGE.md, README.md
```
Scene tree of `fit_runner.tscn`: SkyLayer, Background (Parallax2D hills), Camera, Course (Polygon2D + Line2D terrain, prop scenes you place with
`track_fraction`), Ghost and Runner (same character scene), Qte (QteController), Hud (stamina bar, effort gauge, progress strip, QTE prompt, menus,
all scenes), DebugOverlay (removed unless enabled). Signals are connected in the scene files and zone looks are `FrZoneStyle` nodes.

## Tuning
All numbers live in `FrTuning` (`scripts/sim/runner_tuning.gd`) and `FrQteSettings` (`scripts/qte/qte_settings.gd`). Pass them through
`FitRunnerConfig`, or edit live in the debug overlay. The input schemes are A (hold/release with a sticky cruise band) and B (hold-time tiers);
a third scheme is one subclass of `FrEffortInput` plus a line in `FrEffortFactory`.

## Recovery QTE
Let go and rest; after about 2 s a timing bar appears. Tap while the cursor is on the sweet spot: PERFECT +5 stamina (+0.5 per perfect in a
row), GOOD +2.5, MISS 0. A tap is judged and does not push; holding on after the tap (0.22 s) runs again, no penalty. It also works at the wall.
Customise in `FrQteSettings`: `target_center` / `target_jitter` (where the sweet spot sits), `duration`, `perfect_width`, `good_width`
(difficulty), `rest_time_before_event`, `cooldown`, `only_below_stamina`, `track_from` / `track_to` (when and where on the course), the bonuses, and
the on-screen position (drag `QtePrompt` in `scenes/ui/hud.tscn`, or tick `follow_runner`). Presets: `resources/qte_easy|normal|hard.tres`.

## Defaults and numbers
- Water: let go inside the zone to take the cup (+15 stamina, 1.6 s slowdown). Wall: at 0 stamina pace is capped at 45% until stamina is back to 35;
  holding at the wall stops recovery. Drain is a smooth curve through your four tier numbers. Final spurt: last 15%, pace cap 1.12, drain x0.6.
- Par and the ghost come from a bot that plays the same model with the same input scheme (it ignores the QTE). Stars: par x1.05 / x1.25 / x1.5.
- Two numbers differ from the original brief: sprint drain -5 -> -8 and wall exit 25 -> 35 (with the originals, mashing is only about 6% slower
  than steady pacing). `FrTuning.apply_original_numbers()` restores them.

| Python model | A hold/release | B tiers |
|---|---|---|
| par bot = ghost | 95.4 s | 97.1 s |
| steady 0.62 effort + full spurt | 97.8 s | 106.3 s |
| mash, lets go at the wall | 123.0 s (+29%) | 121.7 s (+25%) |
| mash, never releases | 126.1 s | 126.3 s |
| cutoff (par x1.5) | 143.2 s | 145.7 s |

Mash-and-rest with the recovery QTE at typical skill is +19% behind par on normal (+18% easy, +22% hard); perfect taps +16% / +14% / +12%.
Steady pacing is unaffected. `godot --headless --path . --script res://minigames/fit_runner/tools/strategy_sim.gd` should print the table above
(open the editor once first).
